# Struktur Dokumen: Saat Pengajuan dan Setelah Pengajuan

Draft ke-1, 27 September 2026. Peta ini memisahkan apa yang tim serahkan **saat mengajukan proposal** dan apa yang tim kerjakan serta laporkan **setelah proposal diterima (didanai)**.

Sumber: template PKM 2025 berbasis panduan resmi, ringkasan panduan PKM-KC 2025/2026 hasil penelusuran. PDF panduan resmi tidak bisa saya buka dari lingkungan kerja ini; butir bertanda **[cek]** wajib dicocokkan dengan panduan terbaru.

## A. Tahap pengajuan proposal

### A.1 Kegiatan sebelum mengunggah (masuk ke subbab 3.1 proposal)

| No | Kegiatan | Hasil yang masuk ke proposal |
|---|---|---|
| 1 | Wawancara awal dengan pihak sekolah dan observasi presensi di beberapa sesi | Data masalah di 1.1 (penanda [VERIFIKASI]) |

## B. Tahap setelah proposal diterima (masa pelaksanaan 4 bulan)

### B.1 Urutan kegiatan dan dokumen

| Bulan | Kegiatan (Bab 3.2 proposal) | Dokumen atau luaran |
|---|---|---|
| Awal | Pengumuman pendanaan, kontrak, pencairan dana [cek] | Kontrak/surat perjanjian dari perguruan tinggi |
| 1 | 3.2.1 Persiapan dan perizinan; 3.2.2 Analisis kebutuhan dan survei lokasi | Formulir persetujuan orang tua, penilaian dampak data, data pengukuran awal |
| 1–2 | 3.2.3 Perancangan | Dokumen kebutuhan, prototipe antarmuka |
| 2–3 | 3.2.4 Implementasi | Kode sumber, aplikasi di server |
| 2 | Pelaporan tengah | **Laporan kemajuan** (struktur di B.2) |
| 2–3 | Monitoring dan evaluasi oleh perguruan tinggi/Belmawa [cek jadwal] | Presentasi kemajuan, bukti kegiatan |
| 3 | 3.2.5 Pengujian | Hasil uji fungsional, beban, skenario kecurangan |
| 3–4 | 3.2.6 Uji coba lapangan dan evaluasi | Data sebelum-sesudah, skor SUS, transkrip wawancara |
| 4 | 3.2.7 Pemeliharaan, serah terima, pelaporan | Buku panduan, berita serah terima, **laporan akhir**, **video prototipe**, draf artikel |
| Sepanjang program | Dokumentasi | Akun media sosial, catatan harian kegiatan dan catatan keuangan (logbook) [cek format] |
| Setelah program | Seleksi lanjutan bila lolos | PKP2/PIMNAS [cek] |

### B.2 Struktur laporan kemajuan PKM-KC

Menurut ringkasan panduan PKM-KC 2025, laporan kemajuan tidak memakai halaman sampul dan pengesahan. Isinya:

| Bab laporan kemajuan | Diambil dari proposal | Isi baru |
|---|---|---|
| BAB 1. Pendahuluan | Bab 1 proposal (disingkat) | Pembaruan data sekolah hasil survei |
| BAB 2. Target Luaran | Subbab 1.4 | Status tiap luaran |
| BAB 3. Tahap Pelaksanaan | Subbab 3.2 | Tahap yang sudah dan belum selesai |
| BAB 4. Hasil yang Dicapai dan Potensi Khusus | Tabel 3.1 sebagai acuan target | Gambaran prototipe, fungsi, cara kerja, keunggulan, hasil uji sementara |
| BAB 5. Potensi Hasil | Luaran tambahan (artikel, buku panduan) | Rencana artikel, peluang kekayaan intelektual (misalnya hak cipta program komputer), manfaat bagi sekolah |
| BAB 6. Rencana Tahapan Berikutnya | Jadwal Tabel 4.2 | Langkah menuju 100% target |
| Daftar Pustaka | Daftar Pustaka proposal | Tambahan rujukan bila ada |

### B.3 Struktur laporan akhir

Ringkasan panduan menyebut isi utama laporan akhir terdiri atas **ringkasan, daftar isi, bagian inti (pendahuluan sampai daftar pustaka, maks. 10 halaman), dan lampiran**. Lampiran memuat penggunaan dana dan bukti pendukung kegiatan. Urutan bab di bawah ini adalah usulan yang perlu dicocokkan dengan panduan PKM-KC terbaru [cek].

| Bagian | Isi yang disarankan |
|---|---|
| Ringkasan | Masalah, solusi Hadirku, hasil utama dalam angka |
| Pendahuluan | Dari proposal, diperbarui dengan data survei |
| Tinjauan Pustaka | Dari proposal |
| Tahap Pelaksanaan | Tahap yang benar-benar dijalankan, termasuk perubahan dari rencana |
| Hasil dan Pembahasan | Capaian setiap indikator Tabel 3.1, perbandingan sebelum-sesudah, skor SUS, temuan wawancara, keterbatasan |
| Penutup | Kesimpulan menjawab tiga rumusan masalah, saran untuk sekolah dan pengembangan berikutnya |
| Daftar Pustaka | |
| Lampiran | Penggunaan dana, bukti pendukung (foto kegiatan, tangkapan layar aplikasi, berita serah terima), bukti luaran |

### B.4 Luaran dan tempat penyerahannya

| Luaran | Wajib/tambahan | Diserahkan |
|---|---|---|
| Laporan kemajuan | Wajib | Laman Simbelmawa, bulan ke-2 |
| Laporan akhir | Wajib | Laman Simbelmawa, akhir program |
| Prototipe fungsional (aplikasi web, bot, kode sumber) | Wajib | Didemonstrasikan saat monev; kode diserahkan ke sekolah |
| Akun media sosial | Wajib | Tautan dicantumkan di laporan |
| Video prototipe | Wajib [cek 2026] | Laman Simbelmawa |
| Draf artikel ilmiah | Tambahan | Jurnal nasional terakreditasi SINTA |
| Buku panduan pengguna | Tambahan | Sekolah, saat serah terima |

## C. Ringkas: apa yang ditulis kapan

| Saat pengajuan (bentuk rencana) | Setelah diterima (bentuk hasil) |
|---|---|
| Masalah dari observasi awal | Data pengukuran awal yang lengkap |
| Rancangan konsep di Lampiran 5 | Prototipe yang berjalan |
| Indikator dan target (Tabel 3.1) | Capaian nyata tiap indikator |
| Anggaran rencana (Tabel 4.1, Lampiran 2) | Laporan penggunaan dana dan bukti belanja |
| Jadwal (Tabel 4.2) | Rencana tahap berikutnya (laporan kemajuan), tahap yang dijalankan (laporan akhir) |
| Luaran yang dijanjikan (1.4) | Bukti luaran |

Tulis proposal dengan kata kerja rencana ("tim akan", atau kalimat netral seperti di draf ini). Tulis laporan dengan kata kerja lampau dan angka hasil.
