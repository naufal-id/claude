# Web Absensi SMA Santa Maria 1 Bandung

Tugas desain: web absensi siswa berbasis GPS dan WiFi untuk SMA Santa Maria 1
Bandung (Jl. Bengawan No. 6). Siswa absen dari HP, orang tua memantau jam masuk
dan mengirim izin.

## Isi

| Folder | Isi |
|---|---|
| `01-riset/` | Fakta sekolah dan sumbernya, kebutuhan pengguna, riset teknis GPS dan WiFi, referensi pola |
| `02-desain/` | Dokumen lima arah desain beserta alasan dan laporan Delivery Gate |
| `02-desain/preview/` | Pratinjau HTML yang bisa dicoba. Mulai dari `index.html` |

## Cara membuka

Buka `02-desain/preview/index.html` di browser. Halaman itu berisi pembanding
layar yang sama di lima desain (HP dan laptop), tabel perbandingan, dan tautan
ke tiap desain. Di dalam desain, panel gelap di atas dipakai untuk pindah
desain, berganti peran siswa atau orang tua, dan mencoba skenario posisi.

Semua nama siswa, jam, dan angka kehadiran di pratinjau adalah data contoh.
