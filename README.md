# naufal-id/claude

Repositori kerja untuk proyek website PT Nusa Era Pradana, penyedia jasa tenaga
kerja alih daya di Sumatera Utara.

Isi utama ada di `nusa-era-pradana/`, paket dokumen perencanaan (global, desain,
eksekusi). Fase desain memakai preview HTML mandiri di
`nusa-era-pradana/02-desain/preview/`.

Penamaan berkas mengikuti konvensi `YYYY-MM-DD_nama-berkas_draft-ke-N.md`.
Seluruh konten dalam Bahasa Indonesia.

Folder `riset-fomo-esp32/` berisi analisis gap (tujuh tahap), Bab 1, dan Bab 2 untuk dua calon judul
riset deteksi objek FOMO pada ESP32. Lihat README di folder tersebut.
